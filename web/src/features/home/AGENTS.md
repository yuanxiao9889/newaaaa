# 首页设计基准

用户于 2026-10-09 确认采用当前黑白极简版首页，后续首页更新以这一版为基准。用户后续明确提出的新设计要求优先。

- 视觉方向：纯黑白、大字号衬线标题、充足留白、直角控件、线条分栏，灰色用于辅助文字和分隔线。
- 内容定位：AI API 中转站，突出统一模型接入、请求路由、计费和 API 调用示例。
- 延续当前首屏、模型列表、功能介绍、接入步骤和末尾行动入口的结构；新增内容沿用现有视觉语言。
- 首页默认不使用人物、地球网络背景、彩色渐变或发光效果。
- 样式集中在 `web/src/styles/home.css`，通过 `.home-monochrome` 限定在默认首页内。保持后台和管理员自定义首页的既有行为。
- 继续复用项目的布局、导航、按钮、协议标签页、复制按钮和页脚，保留 New API 与 QuantumNous 的项目标识及署名。
- 维护多语言、移动端布局和键盘可访问性；遵循上级 `AGENTS.md` 的实现与验证要求。
